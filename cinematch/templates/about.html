About This Project

About CineMatch Bollywood

CineMatch Bollywood is a user-friendly movie recommendation website focused on Hindi and Indian cinema. Select Bollywood films you enjoy, and the system compares real viewer likes and movie genres from the existing SQLite database to recommend your best matches.

What Makes It Easy to Use

  • Bollywood-only filtering: Unrelated Hollywood movies are excluded from search and recommendations.
  • Clear visual comparisons: Spot the #1 highest-ranked pick immediately and compare percentages in a chart and table.
  • Honest explanations: Every recommendation explains in plain English why it matched, and never pretends a similarity score is a guaranteed probability.

Dataset & Data Honesty

CineMatch uses the existing MovieLens Latest Small SQLite database without deleting or altering any original records:

  • • {{ meta.bollywood_positive }} positive ratings (≥ 4.0★) recorded across Bollywood & Indian titles
  • • {{ "{:,}".format(meta.total_movies) }} total movies and {{ meta.total_users }} users in the full underlying database

Note on missing data: Because the original database only stores movie IDs, titles (with release years), genres, and positive preference counts, poster image URLs and average star ratings are not present in the dataset. Rather than inventing fake posters or ratings, CineMatch displays clean cinema poster cards and exact positive rating counts from the database.
